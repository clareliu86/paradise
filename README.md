# PARADISE — WebGame

A browser-based Hong Kong urban-horror escape game set in an abandoned hospital.

## Play locally

This is a dependency-free static website. Start any local HTTP server in the project directory, for example:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Controls

- Select the visible choices and hotspots to explore.
- Use the sound button to enable the generated horror ambience.
- Press `Escape` to return to the title screen.

## Project structure

- `index.html` contains the game interface, styles, scene logic, and generated audio.
- `assets/` contains the scene and item artwork.
